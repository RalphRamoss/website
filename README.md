# Ralph — About Me Website

A responsive personal portfolio website made with HTML, CSS, and JavaScript. No framework or build step is required.

## Files
- `index.html` — page content
- `style.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and footer year

## Before publishing
Open `index.html` and replace:
- `your.email@example.com` with your email address
- `your-username` in the GitHub link with your GitHub username
- The LinkedIn link with your own profile URL, if you have one

You can also edit the name, school details, interests, and descriptions to match your latest information.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `about-me-website`).
2. Upload all three website files: `index.html`, `style.css`, and `script.js`. You can upload `README.md` too.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait a little while. GitHub will show your website link in the Pages section.

The file named `index.html` must stay in the repository's root folder.
